# Frontend

This folder is a GitHub-facing guide to the frontend; it is not a separate app package. The frontend is part of the root Next.js application.

## Source locations

- `app/login/` — sign-in screen
- `app/student/` — student dashboard and assignment submissions
- `app/staff/` — staff dashboard and assignment management
- `app/hod/` — department dashboard
- `components/` — shared dashboard header, chatbot, and UI components
- `styles/globals.css` — global styles and dashboard presentation
- `public/` — icons and static images

Run the full application from the repository root with `npm run dev`.
